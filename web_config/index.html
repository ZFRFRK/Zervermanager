Overview

Zervermanager is a lightweight control panel for Debian servers.

  • Dashboard: View the real-time status of your server's core services.
  • Make Site: Automatically generate configurations for Nginx/Apache, create databases, and optionally create DNS zones all at once.
  • Manage Sites: Enable, disable, or completely delete existing web sites and their associated configs.
  • DNS Zones: View and manage BIND9 DNS records.
  • MariaDB: View databases, users, and optionally drop them.
  • Install Services: Manage system packages and create Mailbox users for Postfix/Dovecot.
  • Server: Reboot the server or manage global configurations.
  • Network: View and apply static IP settings.
